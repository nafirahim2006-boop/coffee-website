 Coffee Website

 About the Project

This is a coffee website created using HTML and CSS. It provides a simple and attractive interface to explore coffee and its related content.

Features

* Attractive homepage design
* Coffee-related content
* Simple navigation layout
* Styled web page elements
* User-friendly interface

 Technologies Used

* HTML
* CSS

 Project Files

* `index.html` – Main webpage
* `style.css` – Website styling

 Purpose

This project was developed to practise frontend development and improve HTML and CSS skills.
